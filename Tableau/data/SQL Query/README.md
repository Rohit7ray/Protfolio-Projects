
# COVID-19 Data Retrieval for Tableau using SQL

## Project Overview

This project contains SQL queries used to prepare and retrieve COVID-19 data for Tableau visualizations. The queries aggregate, transform, and analyze global COVID-19 cases, deaths, and vaccination data to create datasets optimized for interactive dashboards and business intelligence reporting.

## SQL Concepts Demonstrated

- SELECT Statements
- Aggregate Functions
- GROUP BY
- ORDER BY
- INNER JOIN
- CAST() and CONVERT()
- Window Functions (`SUM() OVER`)
- Common Table Expressions (CTEs)
- Data Aggregation

## Key Insights

- Calculated global COVID-19 cases, deaths, and mortality rates.
- Compared total deaths across continents.
- Identified countries with the highest infection rates.
- Measured the percentage of the population infected.
- Tracked cumulative vaccination progress using SQL Window Functions.
- Created optimized SQL queries for Tableau dashboards.
