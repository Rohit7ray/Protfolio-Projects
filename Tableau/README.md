# COVID-19 Dashboard using Tableau

## Project Overview

This project presents an interactive Tableau dashboard built using SQL-transformed COVID-19 data. It provides insights into global COVID-19 cases, deaths, infection rates, and geographical trends through dynamic visualizations. SQL was used to retrieve and prepare the data, while Tableau was used to design an interactive dashboard for data analysis and reporting.

## Project Components

This project consists of the following components:

- **Dashboard** – Tableau workbook and dashboard screenshots.
- **Data** – Source datasets and SQL queries used to prepare the data for visualization.

## Technologies Used

- Tableau
- Microsoft SQL Server
- SQL
- SQL Server Management Studio (SSMS)

## Dashboard Features

- Global Total Cases, Total Deaths, and Death Percentage
- Country-wise Population Infection Map
- Population Infection Trends Over Time
- Total Deaths by Continent
- Country-wise Infection Percentage Analysis
- Interactive KPI Cards and Visualizations
