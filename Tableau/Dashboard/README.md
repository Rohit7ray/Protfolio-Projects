# COVID-19 Dashboard | Tableau

## Project Overview

This project presents an interactive Tableau dashboard built using SQL-transformed COVID-19 data. The dashboard provides insights into global COVID-19 trends, including total cases, deaths, infection rates, continent-wise fatalities, and country-level population infection percentages through dynamic and interactive visualizations.

## Features

- Global KPI cards (Total Cases, Total Deaths, Death Percentage)
- Country-wise Population Infection Map
- Population Infection Trend Over Time
- Total Deaths by Continent
- Country-wise Infection Percentage Analysis
- Interactive and dynamic Tableau visualizations

## Technologies Used

- Tableau
- Microsoft SQL Server
- SQL
- Data Visualization
- Geographic Mapping
