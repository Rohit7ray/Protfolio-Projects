# SQL Projects

## Overview

This folder contains SQL projects focused on exploring and analyzing real-world datasets using Microsoft SQL Server. The projects demonstrate SQL concepts such as joins, aggregate functions, window functions, Common Table Expressions (CTEs), temporary tables, and views to extract meaningful business insights.

## Dataset

This project uses two COVID-19 datasets:

- **CovidDeaths** – Contains country-wise COVID-19 cases, deaths, and population data.
- **CovidVaccinations** – Contains global COVID-19 vaccination records.

- **CovidDeaths.sql** – Exploratory data analysis on COVID-19 cases and deaths.
- **CovidDeaths vs CovidVaccinated.sql** – Analysis of vaccination progress using joins, CTEs, and window functions.
