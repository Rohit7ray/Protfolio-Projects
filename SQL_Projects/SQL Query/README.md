# COVID-19 Data Exploration using SQL

## Project Overview

This project focuses on exploring and analyzing COVID-19 data using SQL Server. The analysis provides insights into infection rates, death percentages, vaccination progress, and global COVID-19 trends. It demonstrates how SQL can be used to clean, analyze, and extract meaningful insights from real-world datasets.

## Dataset

The project uses two datasets:

- **CovidDeaths** – Contains country-wise COVID-19 cases, deaths, population, and daily statistics.
- **CovidVaccinations** – Contains daily vaccination data for countries around the world.

- Temporary Tables

## Key Insights

- Calculated COVID-19 death percentage by country.
- Compared infection rates against total population.
- Identified countries with the highest infection rates.
- Identified countries and continents with the highest death counts.
- Analyzed global COVID-19 trends.
- Tracked cumulative vaccinations using SQL Window Functions.
- Created reusable SQL Views for reporting and visualization.
